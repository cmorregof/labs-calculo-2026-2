# Introducción a las Ciencias de la Computación — Laboratorio 1

Este curso hace **el mismo laboratorio que Cálculo Diferencial** (*La factura de la ciudad*, sesión 1): mismo cuaderno, mismos datos, misma guía. Lo que ese laboratorio enseña primero no es cálculo, es computación: qué es un archivo de datos, cómo una máquina lo convierte en una tabla, cómo se le pregunta con código y cómo se decide qué valores son legales antes de operar.
